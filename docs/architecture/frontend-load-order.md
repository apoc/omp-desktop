# Frontend load order (`src/index.html`)

Script order **is** the dependency graph:

1. Vendored libs: React + ReactDOM (development build here; release builds get the production pair — see *Release frontend* below), Babel, `marked.min.js`, `highlight.min.js` → `app/marked-setup.js` (plain, IIFE — wires marked's renderers; needs both libs, and must run before any JSX renders markdown. It also defines `window.OMP_MARKDOWN.fenceCode` *before* its library guard: `changes-panel.jsx` destructures it at top level, `app/message-queue.js` calls it). No inline `<script>` anywhere in `index.html`: the release CSP blocks it and `build-frontend.mjs` fails the build on one.
2. App constants: `app/constants.js` → `app/keymap.js` (plain, IIFE — defines `window.OMP_KEYMAP`; must load before any Babel file that calls `OMP_KEYMAP.matches`/`.keysFor`, including `composer.jsx`, `shortcuts-modal.jsx`, `use-keymap.jsx`) → `mentions.js` (plain, IIFE) → `app/image-attach.js` (plain, IIFE — defines `window.OMP_IMAGES`; `composer.jsx` destructures it at top level) → `app/slash-commands.js` (plain, IIFE — defines `window.OMP_SLASH`; `composer.jsx` and `live.js` both destructure it at top level, so this must load before either) → `app/scroll-pin.js` (plain, IIFE — defines `window.OMP_SCROLL_PIN`; `chat/chat-view.jsx` destructures it at top level, so this must load before it) → `app/prompt-history.js` (plain, IIFE — defines `window.OMP_PROMPT_HISTORY`; `composer.jsx` references it in event handlers, and `live.js` reads it at its own top-level IIFE init — not just inside a later-called function — so this must load before `live.js` too, same constraint as `slash-commands.js`) → `app/subagents.js` (plain, IIFE — defines `window.OMP_SUBAGENTS`; `design/subagents/*.jsx` destructure it at top level and `live.js` reads it at its top-level IIFE init, so this must load before both) → `app/updater.js` (plain, IIFE — defines `window.OMP_UPDATER`; only read inside `design/update-modal.jsx` and `app/use-updater.jsx` function bodies; its `busyTabCount` looks up `window.OMP_TURN_STATUS.isBusyRunState` at call time, a late-bound lookup that `app/turn-status.js` loading later does not break) → `app/lightbox.js` (plain, IIFE — defines `window.OMP_LIGHTBOX`, the attached-image viewer's fit/FLIP geometry; `chat/image-lightbox.jsx` destructures it at top level) → `app/project-nav.js` (plain, IIFE — defines `window.OMP_PROJECT_NAV`, the tab grouping/focus-existing lookups of issue #27 and the history filter chips of #35; `design/chrome.jsx`, `design/tab-group-chip.jsx`, `design/project-sidebar.jsx` and `design/history-modal.jsx` destructure it at top level and `live.js` calls it) → `app/matrix-rain.js` (plain, IIFE — defines `window.OMP_MATRIX`, the empty workspace's rain/logo geometry; `design/empty-workspace.jsx` destructures it at top level) → `app/session-ui.js` (plain, IIFE — defines `window.OMP_SESSION_UI`, the per-tab draft/plan-mode maps of issue #28; `design/composer.jsx`, `app/use-goal-mode.jsx` and `app-live.jsx` destructure it at top level, under different names — Babel scripts share one top-level scope, so a second `const entryOf` would throw at load) → `app/message-queue.js` (plain, IIFE — defines `window.OMP_QUEUE`, the steer/follow-up queue strip's helpers; `design/queue-strip.jsx` and `design/composer.jsx` destructure it at top level, `live.js` reads it at its top-level IIFE init and `app-live.jsx` in its first render) → `app/ask-dialog.js` (plain, IIFE — defines `window.OMP_ASK_DIALOG`, omp's ask dialog rules; `chat/ask-dialog.jsx` and `chat/ask-bubble.jsx` destructure it at top level and `live.js` reads it at its top-level IIFE init). **Before** the `design/` layer *and* before `app/use-bridge-snapshot.jsx` — `profile-menu.jsx`, `chrome.jsx`, `live.js` and `use-bridge-snapshot.jsx` destructure `DEFAULT_PROFILE_ID`/`isSubmitEnter` off `window` at *top level*, and `chrome.jsx` and `thinking-menu.jsx` destructure `THINKING_LEVELS` (omp's thinking levels with their descriptions and status-bar abbreviations), so moving this after any of them silently yields `undefined` (no resolver, no error). `composer.jsx`, `chat/ask-bubble.jsx` and `chat/ask-dialog.jsx` only call `isSubmitEnter` inside handlers — late-bound global lookups, insensitive to script order.
   → `app/conversation-tree-graph.js` (plain, IIFE — defines `window.OMP_CONV_GRAPH`, the conversation tree's entry index and lane layout; `app/conversation-tree.js` destructures it at its top-level IIFE init, so it must load before it) → `app/conversation-tree.js` (plain, IIFE — defines `window.OMP_CONV_TREE`, the conversation tree's pure model; `app/use-conversation-tree.jsx` calls it at render time, so it only has to precede that hook) → `app/goal.js` (plain, IIFE — defines `window.OMP_GOAL`, the goal-mode reducer; `chat/goal-row.jsx`, `design/goal-strip.jsx` and `app/use-goal-mode.jsx` destructure it at top level and `live.js` reads it at its top-level IIFE init).
3. Tweaks: `tweaks/style.js`, `tweaks/use-tweaks.js` (plain, IIFE) → `tweaks/panel.jsx`, `tweaks/controls.jsx` (Babel; controls depends on panel).
4. UI primitives: `ui/use-popover-dismiss.js` (plain, IIFE — defines `window.usePopoverDismiss`, the outside-click/Escape dismissal of `profile-menu.jsx`, `tab-group-chip.jsx` and `thinking-menu.jsx`; called at render time, so only needs to precede them) → `ui/icons.jsx` (defines `Icon`, `TOOL_META`) → `ui/copy-button.jsx` (`copyText`, `CopyButton`, `CopyHost`, `copyCodeBlockClick`; `markdown.jsx`, `plan-annotations.jsx` and the `chat/` cards destructure them at top level) → `ui/sparks.jsx` → `ui/markdown.jsx` → `ui/plan-annotations.jsx`.
5. Chat: `chat/image-lightbox.jsx` → `chat/user-bubble.jsx` (destructures `window.ImageLightbox` at top level) → `chat/eval-cell.jsx` → `chat/assistant-bubble.jsx` → `chat/tool-card.jsx` → `chat/ask-dialog.jsx` (omp's ask dialog; destructures `window.MarkdownContent` at top level) → `chat/ask-bubble.jsx` (destructures `window.AskDialog` at top level) → `chat/retry-row.jsx` (omp's automatic-retry row) → `chat/goal-row.jsx` (goal-mode rows) → `chat/chat-view.jsx` (destructures `window.RetryRow` and `window.GoalRow` at top level).
   Then subagents: `subagents/subagent-bits.jsx` → `subagent-controls.jsx` (steer box + stop button) → `subagent-inspector.jsx` (destructures `SubagentControls`) → `subagent-pane.jsx` (destructures `SubagentInspector`) → `subagent-rail-card.jsx`, all before `chrome.jsx`, whose `AmbientRail` destructures `window.SubagentRailCard` at top level.
6. `design/mention-menu.jsx` → `design/paste-strip.jsx` (collapsed-paste chips of #31) → `design/queue-strip.jsx` (steer/follow-up queue strip; destructures `window.OMP_QUEUE` at top level) → `design/thinking-menu.jsx` (the thinking pill's level menu of #10; destructures `window.Icon` and `window.THINKING_LEVELS` at top level) — `composer.jsx` renders `<PasteStrip>`/`<QueueStrip>`/`<ThinkingMenu>` by their global names, so only render-time order matters (the same goes for its `<TabRunDot>` in the background-job note, defined later by `tab-group-chip.jsx` — never destructure it at the top of `composer.jsx`) → `design/goal-strip.jsx` (the goal strip; `app/use-goal-mode.jsx` destructures `window.GoalStrip` at top level and hands the element to `composer.jsx`) → `design/composer.jsx` → `design/profile-menu.jsx` (before `chrome.jsx`, which destructures `window.ProfileMenu`) → `design/rename-field.jsx` (inline conversation-name editor of #32; before `tab-group-chip.jsx`, `chrome.jsx` and `project-sidebar.jsx`, which all destructure `window.RenameField` at top level) → `design/tab-group-chip.jsx` (before `chrome.jsx`, which destructures `window.TabGroupChip`/`window.TabRunDot` at top level) → `design/chrome.jsx` → `design/project-sidebar.jsx` (destructures `window.TabRunDot` at top level) → `design/empty-workspace.jsx` (destructures `window.MarkdownContent` and `window.OMP_MATRIX` at top level) → `design/panels.jsx` → the remaining panels/modals → `design/shortcuts-modal.jsx` (after `history-modal.jsx`; reads `window.OMP_KEYMAP` at top level) → `design/update-modal.jsx`.
   Then the conversation tree pane, after `update-modal.jsx`: `design/conversation-tree-rows.jsx` (formatters, graph, meter; exports `TreeFmt`, `TreeRow`, `TreeCompaction`) → `design/conversation-tree-detail.jsx` (destructures `TreeFmt`) → `design/conversation-tree.jsx` (destructures all three). Each destructures under a unique alias (`_TD_Fmt`, `_CT_Row`): Babel scripts share one top-level scope.
7. Live data: `model-names.js` → `app/turn-status.js` (plain, IIFE — defines `window.OMP_TURN_STATUS`, run state and turn outcome; `adapter.js` calls it inside `adaptAgentMessages` and `live.js` reads it at its top-level IIFE init, so it must load before both) → `app/transcript-merge.js` (plain, IIFE — defines `window.OMP_TRANSCRIPT`, the get_messages merge and `tsOf`; `adapter.js` calls it inside `adaptAgentMessages` and `live.js` destructures it at its top-level IIFE init) → `adapter.js` → `app/session-title.js` (plain, IIFE — defines `window.OMP_SESSION_TITLE`, the auto-rename/refresh gates plus note/title helpers; `live.js` reads it at its top-level IIFE init, so it must load before `live.js` — misordered, it fails silently at load and throws only on the first send or `get_state`) → `live.js`.
8. `app/use-bridge-snapshot.jsx` (after `live.js`, whose snapshot it mirrors).
9. `app/use-keymap.jsx` (after `live.js` — calls `bridge.listKeybindings`; after `use-bridge-snapshot.jsx`; before `app-live.jsx`).
   → `app/use-subagent-manager.jsx` (UI state for the subagent manager; before `app-live.jsx`).
   → `app/use-updater.jsx` (in-app updater state; before `app-live.jsx`).
   → `app/use-goal-mode.jsx` (goal mode in the composer; destructures `window.GoalStrip`, `window.OMP_SESSION_UI`, `window.OMP_GOAL` and `window.OMP_TURN_STATUS` at top level; before `app-live.jsx`).
   → `app/use-conversation-tree.jsx` (the pane's data flow; before `app-live.jsx`).
10. `app-live.jsx` last.

When adding a file, insert at the correct point — there is no resolver to catch ordering bugs.
