# Frontend load order (`src/index.html`)

Script order **is** the dependency graph:

1. Vendored libs: React + ReactDOM (development build here; release builds get the production pair — see *Release frontend* below), Babel, `xterm.js` → `xterm-addon-fit.js` (the terminal panel's xterm, `scripts/vendor-xterm.mjs`; UMD globals `window.Terminal` / `window.FitAddon.FitAddon`, read only inside `app/terminal-xterm.js` function bodies, so they only have to precede it), `marked.min.js`, `highlight.min.js` → `app/marked-setup.js` (plain, IIFE — wires marked's renderers; needs both libs, and must run before any JSX renders markdown. It also defines `window.OMP_MARKDOWN.fenceCode` and `.isSchemeLikeFilePath` *before* its library guard: `app/message-queue.js` calls the first, and `app/file-preview.js` destructures the second at its IIFE init). No inline `<script>` anywhere in `index.html`: the release CSP blocks it and `build-frontend.mjs` fails the build on one.
2. App constants: `app/constants.js` → `app/keymap.js` (plain, IIFE — defines `window.OMP_KEYMAP`, including `guestShouldBypass`, the one rule for which keys leave a focused terminal or browser page for the app (`app/terminal-xterm.js` and `app/browser-screen.js` look it up at call time); must load before any Babel file that calls `OMP_KEYMAP.matches`/`.keysFor`, including `composer.jsx`, `settings/shortcuts-editor.jsx`, `use-keymap.jsx`) → `mentions.js` (plain, IIFE) → `app/image-attach.js` (plain, IIFE — defines `window.OMP_IMAGES`;
